técnica documentada. Sin esto, cualquier cambio a `branding/` es irreversible
y no sabemos qué herramienta usar para el pipeline DTCG. Además, el flujo
Figma free + Tokens Studio free necesita quedar escrito para que futuros
devs sepan cómo autorizar y exportar tokens.
