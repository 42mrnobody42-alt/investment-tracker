## Contexto

Antes de tocar tokens necesitamos un backup del estado actual y una decisión
técnica documentada. Sin esto, cualquier cambio a `branding/` es irreversible
y no sabemos qué herramienta usar para el pipeline DTCG. Además, el flujo
DTCG escrito a mano necesita quedar escrito para que futuros
devs sepan cómo autorizar y exportar tokens.

- Benchmark DTCG base (Made Reality Designs / IBM Carbon / otros ≥2).
