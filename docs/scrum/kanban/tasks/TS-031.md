## Contexto

Con el manifest (TS-030) generado, esta task implementa `useAsset('clave')`
como hook que resuelve la URL en runtime desde `manifest.json` (fetch una vez,
cachea en memoria). Fallback a placeholder + `console.warn` si la clave no
existe (no rompe la vista). Tests unitarios con Vitest.

## Entregable

- `frontend/src/shared/hooks/useAsset.ts` — hook que resuelve `clave` → URL.
- `frontend/src/shared/hooks/useAsset.test.ts` — tests con `fetch` mockeado.
- `frontend/src/shared/types/assets.types.ts` — tipo `AssetKey` con union de claves del manifest.
- Integración: el hook expone `useAsset('clave')` → `{ url, loading, error }` (o `string` directo, según diseño final).

## Criterios de aceptación

- [ ] **CA_01:** `useAsset('logo.primary')` devuelve `/assets/logos/logo-primary.svg`.
- [ ] **CA_02:** `useAsset('inexistente')` devuelve placeholder (`/assets/icons/placeholder.svg`) + `console.warn`.
- [ ] **CA_03:** El hook cachea el manifest (fetch único) y no re-fetchea por cada llamada.
- [ ] **CA_04:** Tipado estricto: `AssetKey` union autogenerada (o mantenida manualmente) desde `manifest.json`.
- [ ] **CA_05:** `frontend/src/shared/hooks/useAsset.test.ts` con ≥4 tests (éxito, fallback, cache, tipado).
- [ ] **CA_06:** `npm run type-check` exit 0 + `Frontend-test-Dev.sh` verde.
