## Contexto

Con la estructura de TS-025 lista, esta task configura `i18next` +
`react-i18next` + `i18next-browser-languagedetector`. Detecta idioma
automáticamente (`localStorage` → `navigator.language` → fallback `es`),
permite override manual persistido y monta el `I18nextProvider` en
`AppProviders`. Además resuelve ADR-0006 agregando el decorador `withI18n`
de Storybook + toolbar de locale.

## Entregable

- `frontend/src/i18n/index.ts` con `i18n.use(LanguageDetector).use(initReactI18next).init(...)`.
- `frontend/src/app/providers/I18nProvider.tsx` que monta `I18nextProvider`.
- `frontend/src/app/providers/AppProviders.tsx` incluye `I18nProvider`.
- Detector configurado: `order: ['localStorage', 'navigator']`, `caches: ['localStorage']`, `lookupLocalStorage: 'i18nextLng'`, `fallbackLng: 'es'`.
- `frontend/src/shared/hooks/useLanguage.ts` hook con `language`, `changeLanguage`.
- `frontend/.storybook/preview.tsx` con `withI18n` (envuelve stories) + `globalTypes.locale` toolbar (`es`/`en`) + cambio en runtime.
- ADR-0006 (`decorador-with-i18n-pendiente.md`) **eliminado** + fila tachada en README.
