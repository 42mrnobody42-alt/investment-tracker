## Contexto

Con los namespaces e `i18n.d.ts` autogenerado (TS-027), esta task crea los
scripts de validación y regeneración para que el CI bloquee PRs con claves
faltantes y los types se mantengan sincronizados. Los scripts se integran al
runner `Frontend-test-Dev.sh` como nuevo grupo `i18n-check`.

## Entregable

- `frontend/scripts/check-i18n.mjs` — falla si falta clave en es o en, o si hay huérfanas.
- `frontend/scripts/gen-i18n-types.mjs` — regenera `i18n.d.ts` desde los JSON.
- `frontend/package.json` scripts: `"i18n-check": "node scripts/check-i18n.mjs"` + `"i18n-types": "node scripts/gen-i18n-types.mjs"`.
- `frontend/tests/shellTest/Frontend-test-Dev.sh` — nuevo grupo `i18n-check`.
- `frontend/tests/unit/scripts/check-i18n.test.ts` — tests unitarios (fixtures: paridad, faltante en es, faltante en en, huérfana).

## Criterios de aceptación

- [ ] **CA_01:** `node scripts/check-i18n.mjs` exit 0 con JSON en paridad.
- [ ] **CA_02:** `check-i18n.mjs` exit 1 si falta clave en es.
- [ ] **CA_03:** `check-i18n.mjs` exit 1 si falta clave en en.
