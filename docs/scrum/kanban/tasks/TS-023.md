## Contexto

Con la decisión de TS-022 tomada, esta task importa el DTCG base y crea la
capa de overrides de marca. También agrega la Story `DesignTokens/Compare`
para comparar visualmente branding actual vs importado (side-by-side), y
configura Style Dictionary v5 para compilar el DTCG a CSS + TS types.
