## Contexto

Con `public/assets/fonts/` creada (TS-029) pero vacía, esta task puebla la
carpeta con Inter (400, 500, 600, 700) y JetBrains Mono (400) self-hosted,
crea `fonts.css` con `@font-face` + `font-display: swap` + preload del subset
crítico, y actualiza `branding/tipografia.css` para importar `fonts.css`.

## Entregable

- `frontend/public/assets/fonts/` con: `Inter-Regular.woff2`, `Inter-Medium.woff2`, `Inter-SemiBold.woff2`, `Inter-Bold.woff2`, `JetBrainsMono-Regular.woff2`.
- `frontend/public/assets/fonts/fonts.css` con `@font-face` para cada peso + `font-display: swap`.
- `<link rel="preload">` del subset crítico (Inter Regular) en `index.html`.
- `frontend/src/styles/branding/tipografia.css` importa `../../assets/fonts/fonts.css` (o ruta equivalente).
- `frontend/scripts/download-fonts.mjs` (opcional) — script idempotente que descarga las fuentes de Google Fonts o fuente canónica.
- `frontend/README.md` sección "Fonts" con instrucciones.
