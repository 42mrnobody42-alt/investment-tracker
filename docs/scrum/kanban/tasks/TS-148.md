## Contexto

Con las 3 demos de motion listas (TS-147), el usuario elige el ganador en
Storybook. Esta task consolida esa elección: aplica el motion ganador al
Button (sin stories demos) y reemplaza cualquier color/espaciado hardcodeado
por `var(--button-*)` y `var(--motion-*)` del Design System.

## Entregable

- Elección del motion ganador documentada en `docs/scrum/kanban/tasks/TS-148.md` o equivalente.
- `Button.module.css` consume solo tokens: `var(--button-bg)`, `var(--button-fg)`, `var(--button-padding-x)`, `var(--motion-duration)`, `var(--motion-easing)`, etc. (0 hex, 0 px hardcodeado).
- Motion ganador aplicado (el que el usuario eligió de las 3 demos).
- Stories demos (MotionShine/MotionGlow/MotionVibrate) removidas o archivadas.
