## Resumen ejecutivo

**Qué resuelve**: formaliza el lenguaje visual del producto en un sistema
formal de tokens (DTCG 2025.10) que alimenta todos los componentes y permite
theming multi-modo (light/dark/high-contrast) sin duplicar valores.

**Resultado observable**: el Button de la home consume tokens del Design
System, muestra uno de 3 motions (shine sweep / glow pulse / vibrate+shine
elegido por el usuario), el contador de clicks sigue funcionando, y la
Story `DesignTokens/Overview` muestra el catálogo actualizado con tokens
en runtime.

## Contexto

Los tokens de branding actuales viven dispersos en 5 CSS de `branding/`
(`paleta-colores-corporativa.css`, `tipografia.css`, `layout.css`,
`estilos-componentes.css`, `motion.css`). No hay DTCG formal, no hay
`tokens.ts` tipado, no hay build pipeline y el Button de la home es el
starter de Vite en `App.tsx` (no usa Design System).

## Alcance

### Fase A — Investigación y decisión (TS-022)

- Backup `branding/` → `branding-backup-v0.1.14/`.
- Benchmark 4 herramientas (Style Dictionary v5, Tokens Studio, Figma Variables, CSS custom properties) con videos ≤10 min.
- Benchmark DTCG base (Made Good Designs, IBM Carbon, otros 1-2).
- Decisión técnica registrada + doc flujo Figma en `docs/tecnica/04-frontend-react-css-moderno/flujo-de-trabajo/figma/`.

### Fase B — Pipeline DTCG (TS-023, TS-024)

- Estructura `frontend/src/components/imported/` (`atoms/{buttons,cards,searchbar}`, `layout/`, `themes/`, `brand-overrides/`).
- Importar DTCG base + `brand-overrides/` con branding WattVision (cyan + Inter + JetBrains Mono + motion easings).
- Comparación side-by-side (branding actual vs importado) en `DesignTokens/Compare`.
- Style Dictionary v5 build + `tokens.ts` autogenerado + ThemeProvider con persistencia.
- Regenerar los 5 CSS de `branding/`.
- Story `DesignTokens/Overview` actualizada para leer tokens runtime.

### Fase C — Motion + integración (TS-147, TS-148, TS-149, TS-150)

- 3 motion demos en Storybook (shine sweep + lift, glow pulse, vibrate + shine lateral).
- Usuario elige ganador → consolidar.
- Button consume `var(--button-*)` + `var(--motion-*)` (0 hex hardcodeado).
- Integrar Button en `App.tsx` manteniendo el contador de clicks.
- Story `Button` + `DesignTokens/Compare` actualizadas.
